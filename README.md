# Smart Money Algo Frontend Preview v1

Static responsive UI prototype: dashboard, broker setup, net position, trade history, strategy settings, risk management, notifications, profile/billing.

## Local preview
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Safety
This is only a front-end prototype. No trading engine, broker API, account database, payment provider, or notification service is connected. Form controls only show preview messages. Do not enter real credentials or tokens. Do not change domain DNS until the design has been reviewed and production hosting is prepared.

## GitHub Pages
Upload `index.html`, `styles.css`, `app.js`, and `README.md` into the repository root, then set Settings → Pages → Deploy from a branch → `main` → `/(root)`.
